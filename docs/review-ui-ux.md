# UI/UX 与皮肤呈现评审及优化结果

## 结论

在 480×720 与 360×640 两个视口共采集 50 张截图（每个视口 25 张）。未发现 P0 阻断项。已完成本轮裁定的触控目标、升级 Toast、术语、低对比度和 HUD 反馈优化；机库机体外观预览是新增功能，按范围暂缓。

原始截图与量测数据保存在被 Git 忽略的 `.clawbench/shots/`，不会随提交上传。可交互皮肤入口不存在：当前只有固定的 `neon` 视觉风格；44 是贴图 id 数，不是 44 款可选皮肤。

### 升级 Toast

升级三选一正在绘制时，`drawLevelUp` 记录抑制时间，`drawToast` 跳过同帧提示（`js/ui/overlays.js:97,311-312`）。升级弹窗关闭后提示恢复。截图：[升级选择（有待显示 Toast）](../.clawbench/shots/360x640/levelup-choice-with-toast.png)；回归测试验证 Toast 不覆盖选择项（`test/ui.test.mjs`）。

### 文案与对比度

- 商城“金币加成”改为“得分加成”，技能名“幸运金币”改为“幸运得分”；暂停技能摘要也统一为“得分”。运行时代码与测试中 `金币` 搜索无匹配。
- 图鉴未点亮技能/道具名称改为 `#b8c5dc`，副文案改为 `#aebbd2`（`js/ui/codex.js:119,199`）；商城副文案改为 `#c2ccdd`（`js/ui/menus.js:342`）。
- 截图像素复核（360×640）：图鉴名称采样背景 `(9,14,28)`、字形像素 `(183,196,219)`，对比度 10.94:1；图鉴说明背景 `(9,14,28)`、字形 `(164,176,199)`，8.81:1。旧版透明白色合成估算分别为 2.63:1（30%）和 1.95:1（22%）。
- 商城说明采样背景 `(12,15,26)`、字形 `(148,157,172)`，6.99:1；旧版 50% 白色合成估算为 5.33:1。以上结果均超过 WCAG AA 的 4.5:1；采样包含字体抗锯齿，按截图实际字形像素计算。

### HUD 受击与低血提示

`js/hud.js:13-39` 按玩家生命减少触发 120ms 全屏红闪，不拦截输入；仅剩一条命时增强红色边框提示。截图可见：[受击红闪](../.clawbench/shots/480x720/hud-after-hit.png)、[低血边缘提示](../.clawbench/shots/480x720/hud-low-health.png)。`test/theme-hud.test.mjs` 覆盖掉命触发、重复触发与低血边框。

像素复核：受击截图的安静背景区域平均 RGB 红通道由满血 `29.9` 升至 `54.2`（绿 `32.7→32.6`、蓝 `59.4→58.4`）；四周 10% 边缘区域红像素占比由满血 `0.70%` 升至受击 `54.69%`、低血 `61.67%`，确认两种提示都在真实画面触发。

## 暂缓与边界

- **机库外观预览**：截图显示六张战机卡只含文字/数值，没有外观图；这是新功能而非本轮缺陷修补，暂不扩展范围。
- **技能升级动画中的 Toast**：`skillup-animation-with-toast.png` 可见提示覆盖动画面板文字。本轮按裁定只修复升级三选一期间的遮挡；动画 Toast 仍需单独处理。
- **商城副文案字号**：对比度已提高，但 360×640 下字号仍偏小；可在后续调整字号或缩短文案，不影响本轮 AA 对比度结果。
- **皮肤系统**：`SKIN_STYLE` 固定为 `neon`，无玩家换肤入口；44 个 id 是贴图清单。不要把它描述为 44 款可选皮肤。
- **未发现 P0**。本轮 UI 相关测试 `32/32` 通过。

## 最终验证

- `npm test`：**356/356** 通过。
- `tools/uidump/shoot.mjs`：两个视口各采集 25 张截图；量测命中区均达标。
- 冒烟：无限模式、菜单战役入口、`campaign-01` URL 直通、无效关卡回退四条路径均通过。

## 收官状态（待随 v0.4.3 上线）

**已实施**：小屏触控热区（去重 **120 个控件全部 ≥44 CSS px**，18 屏两两重叠 **0 对**）、Toast 在升级三选一期间让位、术语统一（全仓「金币」0 残留）、图鉴/商城对比度（最低 **9.41:1**，≥ WCAG AA 4.5:1）、受击 120ms 全屏红闪 + 低血红边增强（像素复核：低血边缘 R +144%、360×640 红占比 0.85%→3.27%）。
